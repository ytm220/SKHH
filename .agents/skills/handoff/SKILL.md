# handoff

1. REQUIREMENTS.md, DECISIONS.md, `git log --oneline -10`만 읽고 HANDOFF.md를 30줄 이내로 쓴다.
   - 목표: 한 문장
   - 확정 요구: 꼭 필요한 것 / 하지 않는 것
   - 지금까지의 결정: DECISIONS.md에서 핵심만
   - 현재 상태: 동작하는 것 / 아직 안 된 것
   - 가정: 아직 확인하지 않은 것
2. 위임할 일이 있으면 '맡길 일'을 덧붙인다.
   - 수정할 파일 / 건드리지 않을 파일
   - 완료 기준: 무엇을 실행하면 성공인지
   - 돌려줄 내용: 바꾼 파일, 확인 결과, 막힌 점
   - 범위 밖 기능은 만들지 말고 제안만 하라는 지시
3. 위임이면 HANDOFF.md를 지시로 서브에이전트를 띄운다. 새 세션용이면 첫 메시지로 쓸 한 줄을 알려준다: "AGENTS.md와 HANDOFF.md를 읽고 이어서 진행해."
4. git commit 한다.

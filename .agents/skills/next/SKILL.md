# next

1. README.md, REQUIREMENTS.md, DECISIONS.md, `git log --oneline -5`만 읽는다. 없는 파일은 건너뛰고, 폴더 전체를 훑지 않는다.
2. REQUIREMENTS.md를 만들거나 고친다. 확인되지 않은 내용은 '가정'에 둔다.
   - 목표: 한 문장
   - 사용자와 사용 환경
   - 꼭 필요한 것 / 있으면 좋은 것 / 하지 않는 것
   - 확인된 제약
   - 가정: 담당자에게 아직 확인하지 않은 것
3. DECISIONS.md가 없으면 표 머리만 만든다: `결정 | 이유 | 버린 대안`. 작업 폴더가 git 저장소가 아니면 git init 후 첫 commit을 한다.
4. 아래 형식으로만 답하고 멈춘다. 전체 10줄 이내.
   - 지금까지: 확인된 것 한 줄 / 아직 가정인 것 한 줄
   - 다음 한 걸음: 선택지 2개와 장단점 한 줄씩, 추천 하나 표시. 아직 아무것도 없으면 첫 버전으로 완성할 핵심 기능과 구조(파일 구성, 기술 선택, 데이터 저장 방식)를 선택지에 담는다.
   - 지금 내가 할 일: 선택지 중 고르기
   - 확인이 필요한 것: 최대 3개, `요소 — 지금의 가정 — 답에 따라 달라지는 것`
5. 내가 고르면 DECISIONS.md에 기록하고, 그 한 걸음만 진행한다.

# loop

1. 전달받은 내용을 REQUIREMENTS.md에 반영한다. 새로 정해진 '하지 않는 것'도 적는다.
2. 이번 단계에서 바꿀 것을 한 줄로 말하고, 그 범위 안에서만 바꾼다. 바꾸는 부분은 AGENTS.md 1번의 완성도 기준으로 마무리한다. 범위 밖의 개선은 제안만 한다. 구현이 길고 수정할 파일이 정해져 있으면 서브에이전트 위임을 한 줄로 제안하고, 내가 승인하면 handoff 스킬로 넘긴다.
3. 테스트나 요청 한 번으로 오류가 없는지 확인한다. 서버를 새로 띄우거나 다시 띄워야 하면 실행 명령을 알려준다.
4. 사용자가 정한 방향이 있으면 DECISIONS.md에 한 줄 추가한다.
5. git commit 한다.
6. 바꾼 것과 이유, 화면에서 확인할 것, 아직 가정인 것 하나, 다음 후보를 짧게 알린다.
